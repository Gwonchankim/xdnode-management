# 재무 경보 보고·마감 연계 기획서

## 평가

재무 경보 조치센터, 일일 자금일보, 월간 경영보고, 월마감 통제는 각각 영속 원장과 동결 스냅샷을 갖고 있었지만 경보 처리 결과가 세 보고·마감 기능의 공식 원천에 포함되지 않았다. 따라서 중요한 경보가 미해결이어도 보고서와 월마감이 별도로 진행될 수 있었다.

## 개선 원칙

- 보고일 또는 회계 기준일 이후에 발생한 사건은 과거 스냅샷에 포함하지 않는다.
- 현재 사례 상태를 그대로 복사하지 않고 기준일까지의 추가형 이벤트를 순서대로 재생해 상태를 재구성한다.
- 현재 진행 중인 월은 미래 월말이 아니라 최신 재무 원천 기준일을 사용한다.
- 저장된 자금일보·경영보고·제출된 월마감은 당시 경보 요약을 함께 동결하며 이후 상태 변화로 덮어쓰지 않는다.
- 기존 저장본에 경보 스냅샷이 없는 경우 화면은 `연계 전 저장본`과 미확정 값(`-`)으로 표시해 0건으로 오인되지 않게 하고, 새 버전부터 연계를 적용한다.

## 기능별 정책

### 일일 자금일보

- 보고일 기준 미해결, 중요, 종료 검토, 기한 경과 건수를 저장한다.
- 미해결 중요 경보가 있으면 통제경고에 추가한다.
- AI 및 규칙 기반 분석 입력에 동일한 경보 스냅샷을 제공한다.
- 보고서에서 경보 조치센터로 이동할 수 있다.

### 월간 경영보고

- 보고 기준일 경보 조치 원장을 공식 원천 등록부에 추가한다.
- 미해결 경보를 품질경고와 자동 위험 문안에 포함한다.
- 중요도, 담당자, 기한, 증빙 수를 보고서 화면에서 확인한다.
- 제출 시 다른 재무 수치와 함께 경보 상태를 동결한다.

### 월마감 통제

- 중요도가 `HIGH` 또는 `CRITICAL`인 미해결 경보는 자동 통제 실패로 분류하여 제출을 차단한다.
- `NORMAL` 또는 `LOW` 미해결 경보만 남은 경우 담당자의 수동 검토 완료를 요구한다.
- 미해결 경보가 없으면 자동 통과한다.
- 제출 후에는 당시 통제 결과를 기존 월마감 스냅샷에 보존한다.

## 검증 기준

- 종료 승인 후 재개방된 사례는 기준일 상태가 다시 미해결로 계산되어야 한다.
- 기준일 당일 만기 경보는 기한 경과로 계산하지 않아야 한다.
- 미해결 중요 경보가 존재하면 월마감 `canSubmit`이 거짓이어야 한다.
- 자금일보·경영보고의 저장 스냅샷에 경보 요약과 사례 목록이 포함되어야 한다.
- 기존 보고서에 새 필드가 없어도 화면이 중단되지 않아야 한다.
