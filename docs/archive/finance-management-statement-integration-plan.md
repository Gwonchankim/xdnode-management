# 경영보고 전기 손익·마감 무결성 통합 기획

## 1. 기획

월간 경영보고서에 총계정원장의 전기 완료 손익과 비교 기준, 월마감 원장 무결성 상태를 함께 동결한다. 경영진은 세금계산서 공급가액과 회계상 손익을 혼동하지 않고, 제출 시점의 원장이 마감 근거와 일치하는지 한 화면에서 판단할 수 있어야 한다.

## 2. 현행 평가

- 기존 보고서는 Clobe 매출·매입 세금계산서의 공급가액, 자금, 미수, 급여, 예산, 마감 상태를 함께 보여준다.
- 공급가액 순차이를 매출총이익이 아니라고 명시한 점은 적절하지만, 승인 개시잔액과 `POSTED` 전표로 계산한 매출·비용·순이익이 없다.
- 월마감 상태는 `CLOSED` 여부만 확인해 제출 후 원장 계보가 바뀌어도 경영보고서에서 알 수 없다.
- 일반 품질경고는 사용자가 확인하면 제출할 수 있으므로, 마감 원장 변동처럼 선행 해결이 필요한 문제와 구분되지 않는다.

## 3. 기획안 개선

- 전기 손익을 공급가액 분석과 별도 구간으로 둔다.
- 직전 비교는 같은 일수의 2026 전기 원장, 전년 비교는 현재 기간에 완전히 포함된 2025 결산월만 사용한다.
- 부분월은 전년 수치를 일할 계산하지 않는다.
- 기존 승인 보고서의 동결 스냅샷은 수정하지 않는다. 새 필드가 없는 과거 버전은 ‘당시 값 미확정’으로 표시한다.
- 마감 제출 시 동결한 해시와 현재 원장 해시가 다르면 `CLOSE_LEDGER_DRIFT` 차단 경고를 만든다.
- 일반 품질경고는 확인 후 제출할 수 있지만, 원장 변동 차단 경고는 재개방·재마감·보고서 원천 새로 반영 전까지 제출할 수 없다.

## 4. 구축 범위

- 공용 원장 계산기에 조회기간 손익 스냅샷과 해시 변동 평가 함수를 추가한다.
- 월간 경영보고 스냅샷에 현재 손익, 직전 동일 일수, 2025 동일 완료월, 전기 행 수와 차대변 차이를 저장한다.
- 월마감 스냅샷의 원장 해시를 현재 원장과 비교하고 결과를 마감 구간·품질경고·원천 등록부에 저장한다.
- 자동 보고 문안에 전기 손익을 추가한다.
- 보고 화면에 전기 손익 요약·비교표·정확한 기간과 원천을 표시한다.
- 차단 경고가 있으면 서버와 화면 양쪽에서 결재 제출을 막는다.

## 5. 검증 기준

- 전기 손익은 승인 개시잔액과 `POSTED` 통제분개·지급전표만 사용한다.
- 전기 행의 기간 차변과 대변이 다르면 손익 상태는 검토용이어야 한다.
- 현재월 부분기간에는 2025 동일 완료월 비교가 없어야 한다.
- 이전 승인 스냅샷에 신규 필드가 없어도 화면이 중단되지 않아야 한다.
- 동결·현재 해시가 다르면 경영보고 품질경고와 제출 차단이 모두 발생해야 한다.
- 단순 품질경고는 기존의 명시적 확인 제출 흐름을 유지해야 한다.
- 전체 테스트와 배포 빌드가 성공한 경우에만 운영 버전을 갱신한다.
