# 재무제표 비교·마감 후 원장 변동 감지 기획

## 1. 기획

운영 재무제표를 단순 현재값 조회에서 비교 가능한 경영 판단 화면으로 확장하고, 제출·잠금된 월의 원장 계보가 뒤늦게 바뀌면 즉시 확인할 수 있게 한다.

- 2026 현재값은 승인된 개시잔액과 `POSTED` 상태의 통제분개·지급전표만 사용한다.
- 직전 기간은 선택한 조회기간과 일수가 같은 바로 앞 기간을 사용하되 2026년 이전으로 넘어가면 비교하지 않는다.
- 전년 비교는 2025년 확정 월별 결산자료 중 현재 조회기간에 완전히 포함된 동일 월만 사용한다.
- 부분월은 일할 계산하지 않는다. 2026-01-01~08-15 조회라면 2025-01-01~07-31만 비교한다.
- 2025년 월별 자료의 비용은 `매출-순이익`으로 역산한 총비용이며 화면에 산식을 명시한다.
- 재무상태 참고값은 2025-12-31 결산 총자산·현금·매출채권·매입채무·차입금으로 한정한다. 총부채·자본 비교로 오인시키지 않는다.

## 2. 평가와 기획안 개선

초기 안의 ‘전년 동기’는 부분월을 같은 날짜까지 비교할 근거가 없어서 과도한 정확성을 암시했다. 따라서 확정된 완료월만 비교하도록 보수적으로 개선했다. 직전 기간은 모두 동일한 2026 운영 원장을 사용하므로 일수 기준 비교를 허용한다.

마감 이후 변동을 금액 합계만으로 찾으면 같은 금액의 전표 교체를 놓칠 수 있다. 제출 시점의 개시잔액 세트·원천 체크섬·전기행 식별자·일자·계정·차대변을 정렬해 만든 SHA-256 원장 해시를 기준으로 비교한다.

## 3. 구축 규칙

- 총계정원장 API는 현재·직전 동일 일수·2025 동일 완료월 손익과 각 비교의 정확한 기간·원천을 반환한다.
- 화면은 세 비교값과 현재 대비 증감률을 함께 표시하고, 분모가 0이면 비교율을 계산하지 않는다.
- 월마감 제출 시 저장된 `ledgerSnapshot`은 기존처럼 불변 근거로 유지한다.
- 제출 또는 잠금 상태를 조회하면 같은 기준일의 현재 원장 해시를 다시 계산해 동결 해시와 비교한다.
- 해시가 다르면 행 수, 합계 변동, 개시잔액 계보 변동 여부를 표시한다.
- 변동을 감지해도 전표를 자동 수정하거나 마감을 자동 재개방하지 않는다. 잠금월은 승인된 재개방 절차로만 변경한다.

## 4. 검증 기준

- 날짜 경계: 2026-01-01 시작 조회는 직전 기간 비교가 불가해야 한다.
- 완료월 경계: 2026-01-01~08-15는 2025년 1~7월만 포함해야 한다.
- 부분월 경계: 2026-08-01~08-15는 2025 비교값이 없어야 한다.
- 순이익과 비용 역산이 월 합계에서 일치해야 한다.
- 동결·현재 해시가 같으면 일치, 다르면 변동으로 판정해야 한다.
- 해시 경보는 회계 정확성 자체의 보증이 아니라 원장 계보 무결성 확인임을 유지한다.
- 전체 테스트와 배포 빌드가 성공한 경우에만 운영 버전을 갱신한다.
