# 월간 경영보고 자동화 기획·평가서

## 목적

재무 화면에 흩어진 2026년 매출·매입, 은행 잔액, 미수금, 급여, 예산·실적, 월마감 결과를 월 단위 경영보고서로 묶는다. 보고서에 표시되는 모든 수치는 원천, 기준일, 확정도를 함께 남기며 제출 이후에는 수정하지 않는다.

## 원천 평가

| 구간 | 원천 | 보고 가능한 값 | 제한과 표시 원칙 |
| --- | --- | --- | --- |
| 매출·매입 | Clobe 세금계산서 스냅샷 | 월 공급가액, 문서 건수, 공급가액 순차이 | 손익계산서 매출·매출원가가 아니므로 `공급가액`으로 명시 |
| 자금 | Clobe 은행 계좌·잔액 추이 | 원화·외화 환산잔액, 대출, 월내 잔액 추이 | 해당 월 말 또는 최신 기준일이 없으면 `부분 연결`로 표시 |
| 분개 품질 | Clobe 분개장 요약 | 최신 누적 라인 수, 차변·대변, 불일치 | 월 손익이 아니라 최신 누적 품질 지표로 표시 |
| 미수금 | ERP 미수 관리원장 | 관리잔액, 연체·미계획 건수 | 자동 회계잔액이 아니며 기록이 없으면 `미연결`, 0원으로 간주하지 않음 |
| 급여 | ERP 급여 실행원장 | 인원, 지급총액, 공제, 실지급, 마감상태 | 해당 월 실행원장이 없으면 `미연결` |
| 예산 | ERP 승인 예산·실적 매핑 | 월 예산, 자동 연결 실적, 차이, 경보·미매핑 | 승인 예산만 사용하고, 부서가 없는 원천은 전사 예산만 자동 대사 |
| 월마감 | ERP 월마감 통제 | 상태, 자동통제, 수동체크, 증빙 | 월마감 원장이 없으면 보고서 품질 경고 |

## 확정 기획

1. 월별 보고서는 `DRAFT → SUBMITTED → APPROVED` 상태를 가진다.
2. 초안은 최신 원천으로 다시 생성할 수 있지만, 제출·승인본의 수치와 서술은 불변이다.
3. 승인본을 수정해야 하면 사유를 입력하고 새 버전을 만든다. 기존 승인본은 새 버전 승인 시 `SUPERSEDED`가 된다.
4. 자동 분석은 외부 AI가 값을 추측하지 않고 확정 규칙으로 초안을 만든다. 사용자는 성과, 위험, 의사결정 요청 문구를 편집한다.
5. 모든 섹션은 원천명, 기준일, 품질상태, 관련 화면 이동 경로를 가진다.
6. 위험·의사결정은 담당자와 기한이 있는 후속조치로 등록하며 승인 뒤에도 진행상태를 갱신할 수 있다.
7. 누락·부분연결 원천이 있으면 제출 전에 품질경고 확인을 명시적으로 받아 감사기록에 남긴다.
8. 보고서는 브라우저 인쇄 형식으로 출력할 수 있으며 ERP 메뉴·버튼은 인쇄에서 제외한다.

## 검증 기준

- 동일 기간·버전 중복 방지와 승인본 불변성
- 최신 초안 재생성 시 사용자 서술 보존
- 매출·매입 월 합계와 정적 Clobe 스냅샷 일치
- 원화·외화·대출 및 잔액 기준일 표시
- 미수·급여·예산·월마감 미존재를 0으로 오인하지 않음
- 품질경고 미확인 제출 차단
- 승인 반려, 최종 승인, 새 버전 생성, 기존 승인본 대체 동작
- 후속조치의 담당자·기한·상태 저장 및 지연 알림 연결
