# 연말 매출 전망·계좌 위험도 계산 모델

## 1. 평가

- 기존 연말 예상 매출은 2026년 경과일 225일을 화면 코드에 고정해 기준일이 바뀌면 산식이 낡는다.
- 기존 계좌 위험 점수는 결과만 노출되고, 배점·임계값·관측 근거를 사용자가 역산하기 어렵다.
- 화면과 AI 어시스턴트가 각자 문장을 보유해 같은 질문에 서로 다른 숫자를 답할 위험이 있다.

## 2. 개선 기획

### 연말 매출 전망

- 원천은 기준일까지 발행된 전자세금계산서 공급가액이다.
- 기준일에서 경과일·잔여일·윤년 여부를 자동 계산한다.
- 남은 기간의 일평균은 실제로 관측된 세 가지 추세만 사용한다.
  - 보수: 최근 30일·90일·연초 이후 일평균 중 최저값
  - 기준: 연초 이후 일평균
  - 낙관: 최근 30일·90일·연초 이후 일평균 중 최고값
- `누적 실적 + 잔여일 × 시나리오 일평균`으로 계산한다.
- 보수와 기준이 같은 경우 억지로 범위를 벌리지 않는다. 이는 관측된 최저 추세가 연초 이후 평균과 같다는 의미다.
- 계절성·수주잔고·반품·취소·영업계획은 반영하지 않으며 예산이나 확정 매출로 취급하지 않는다.

### 계좌 운영 조기경보

- 초기 모델 버전은 `2026.08-v1`이며, 회사 정책 연동 후 `2026.08-v2`로 개정한다. 총점은 100점이다.
- 대출 커버리지 30점, 외화 집중 20점, 관측기간 고점 대비 감소 20점, 잔액 중앙값 대비 수준 20점, 10만원 미만 운영계좌 10점으로 구성한다.
- 각 항목에 관측값, 판정 규칙, 부여점수, 최대점수를 함께 표시한다.
- 0~29점 안정, 30~59점 주의, 60점 이상 높음으로 구분한다.
- 회사의 최소 운영자금·외화 한도 정책이 등록되지 않았음을 항상 노출한다.
- 이 점수는 신용평가나 지급불능 판정이 아니다. 지급예정표와 확정 수금일이 연결되면 다음 버전에서 보강한다.

## 3. 구축 범위

- 화면과 AI 어시스턴트가 `finance-decision-model.ts`의 동일 계산 결과를 사용한다.
- 매출 화면은 세 시나리오와 산식의 데이터 범위를 표시한다.
- 자금 화면은 총점과 다섯 개 위험요인의 배점을 표시한다.
- 정적 재무 스냅샷을 변경하지 않고 순수 계산 모듈만 추가한다.

## 4. 검증 기준

- 2026-08-13은 연초부터 225일, 연말까지 140일로 계산되어야 한다.
- 누적 실적은 원천의 매출 공급가액 합계와 일치해야 한다.
- `보수 ≤ 기준 ≤ 낙관`, 모든 전망은 누적 실적 이상이어야 한다.
- 위험 총점은 개별 배점 합계와 같고 100점을 넘지 않아야 한다.
- 대출이 없거나 잔액 이력이 비어 있어도 0으로 나누거나 무한대가 표시되지 않아야 한다.
- 화면과 AI 라우트 모두 공통 계산 모듈을 사용해야 한다.
