# 사용자별 오늘 업무 워크벤치 기획·평가

## 1. 현재 평가

- 상단 통합 업무함은 서버 업무를 보여주지만 담당자와 무관한 업무까지 한 목록에 섞일 수 있다.
- 경영보고의 개별 의사결정 안건과 후속조치는 집계 알림만 생성되어 실제 담당 업무를 바로 찾기 어렵다.
- 결재·시스템 경보처럼 원천 절차를 거쳐야 하는 항목을 일반 업무처럼 완료하면 통제를 우회할 수 있다.
- 사용자가 오늘 우선 처리할 항목을 고정하거나 잠시 미루고 개인 메모를 남길 영속 공간이 없다.

## 2. 개선된 원칙

1. 워크벤치는 로그인한 ERP 사용자의 사번을 기준으로 본인 담당 항목만 조회한다.
2. 원천은 `ERP 업무`, `경영보고 후속조치`, `경영 의사결정`으로 구분해 하나의 읽기 모델로 합친다.
3. 후속조치·의사결정의 집계형 시스템 업무는 제외하여 같은 일을 두 번 보여주지 않는다.
4. 상태의 진실은 각 원천 원장이 소유한다. 워크벤치에서 시작·완료를 누르면 기존 원천 API를 호출하고, 결재·재무 경보·의사결정은 관련 화면에서만 확정한다.
5. 워크벤치는 `고정`, `미루기`, `개인 메모`만 별도 개인 원장에 저장한다.
6. 정렬은 고정 → 기한 경과 → 오늘 → 예정 → 중요도·세부기한 순이며, 미룬 항목은 지정일까지 집중 목록에서 분리한다.
7. 개인 설정은 직원별 복합 고유키로 중복 저장을 막고 다른 사용자가 읽거나 수정할 수 없게 한다.
8. 빠른 상태변경은 해당 원천 모듈의 쓰기 권한이 있을 때만 노출한다. 권한이 없으면 본인 업무를 확인하고 관련 화면으로 이동할 수만 있다.

## 3. 화면과 동작

- 요약: 오늘, 기한 경과, 중요, 결정 대기, 미룬 업무
- 집중 목록: 원천·업무영역·상태·기한·설명·개인 메모
- 빠른 작업: 고정/해제, 내일 이후 지정일까지 미루기, 메모, 처리 시작, 완료, 관련 화면 열기
- 통제 항목: 결재·재무 시스템 경보·경영 의사결정은 완료 버튼 대신 원천 화면 이동만 제공

## 4. 검증 기준

- 다른 직원의 담당 업무가 응답에 포함되지 않아야 한다.
- 집계형 경영보고 업무와 개별 안건·조치가 중복 노출되지 않아야 한다.
- 미루기 날짜가 지난 항목은 자동으로 집중 목록에 복귀해야 한다.
- 개인 설정은 같은 직원·원천 항목당 한 행만 존재해야 한다.
- 원천 업무의 상태를 개인 설정으로 덮어쓰지 않아야 한다.
- 기존 통합 업무함과 각 모듈의 업무 처리 기능은 그대로 동작해야 한다.
