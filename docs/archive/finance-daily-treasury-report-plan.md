# 일일 자금일보 통제 기획

## 평가 결과

- 기존 `자금일보 작성` 버튼은 범용 팝업을 닫고 “임시 저장” 알림만 표시해 실제 보고서·감사이력·검토상태가 남지 않았다.
- 대시보드의 자금일보 문구와 일부 수치는 정적 값이어서 Clobe 최신 스냅샷과 달라질 수 있었다.
- 은행거래, 13주 예측, 매출채권, 매입채무, 차입금 일정은 각각 존재하지만 일일 의사결정 단위로 동결되지 않았다.

## 개선된 운영 모델

1. 보고일별 원천 스냅샷을 서버에서 계산하고 JSON으로 동결한다.
2. 같은 보고일의 보고서는 버전을 갖는다. `FINAL` 보고서는 수정하지 않고 다음 버전으로만 개정한다.
3. AI는 동결 스냅샷의 설명만 작성하며 숫자를 생성하지 않는다.
4. AI 설정 누락·무료한도 초과·통신 실패 시 규칙 기반 분석을 저장하고 실패 유형을 표시한다.
5. 담당자가 경영 메모와 후속조치를 저장해야 `REVIEWED`가 되며, 승인 권한자가 최신 원천 여부를 확인해 `FINAL`로 확정한다.
6. 알림 센터는 최신 기준일 보고서가 없거나 미확정이면 업무를 생성한다.
7. 월마감은 해당 월의 최신 원천일 기준 확정 자금일보를 통제 항목으로 검사한다.

## 스냅샷 구성

- 전일/당일 은행성 자산, 원화 예금, 외화 예금 원화환산, 대출 잔액
- 당일 입금·출금·순증감·거래 건수·미분류 거래
- 향후 7일 수동 자금예측 입출금
- 향후 7일 회수 예정 매출채권, 지급 예정 매입채무, 차입금 상환 일정
- 누적 분개장 건수·차변·대변·차이, 보통예금 계정 순증감

## 검증 기준

- `(보고일, 버전)` 중복 금지, 확정본 불변
- 보고일은 2026년이며 최신 Clobe 기준일을 초과할 수 없음
- 스냅샷 수치는 클라이언트 입력을 신뢰하지 않고 서버 원천에서 계산
- 빈 메모·후속조치로 검토 완료 불가
- AI 실패가 보고서 생성을 막지 않으며 대체경로가 명시됨
- 최신 보고서의 미확정 상태가 알림과 월마감 통제에 반영됨
