# 재무 차트 기간 집계 기획

## 1. 평가

- 기존 자금 차트는 `financeCurrentData.balanceTrend`와 같은 값을 화면에 다시 복사해 두어 다음 Clobe 갱신 시 서로 어긋날 수 있었다.
- 월간 자금 차트의 2026년 5월 값은 현재 잔액 추이 원천의 시작일(2026-06-05)보다 앞서 있어 근거를 확인할 수 없었다.
- 기존 ‘연동 채널 매출’은 2026년 6월 단일 채널 21,510,000원만 표시했다. 반면 같은 대시보드의 누적 매출은 전자세금계산서 공급가액 39,066,623,170원이어서 지표 범위가 달랐다.
- 잔액은 특정 시점 값이고 매출은 기간 합계인데 동일한 방식의 고정 배열로 다루고 있었다.

## 2. 개선한 집계 원칙

### 자금 잔액

- 일: 최신 14개 관측일을 시간순으로 표시한다.
- 주: 월요일~일요일 단위로 묶고 각 주의 마지막 관측 잔액을 표시한다.
- 월: 각 월의 마지막 관측 잔액을 표시한다.
- 분기: 각 분기의 마지막 관측 잔액을 표시한다.
- 원천에 없는 기간은 0원이나 추정값으로 채우지 않는다.

### 전자세금계산서 매출 공급가액

- 일: 기준일까지 최근 14일을 표시하고 발행이 없는 날은 0원으로 표시한다.
- 주: 최근 10주 공급가액을 합산한다.
- 월: 기준연도 1월부터 기준월까지 합산한다.
- 분기: 기준연도 1분기부터 현재 분기까지 합산한다.
- 수정·취소분을 포함한 원천 순액을 그대로 더하며, 은행의 매출성 입금이나 판매채널 정산액과 합치지 않는다.

## 3. 표시 원칙

- 차트 제목을 ‘연동 채널 매출’에서 ‘세금계산서 매출 공급가액’으로 바꾼다.
- 잔액형은 ‘구간 말 잔액’, 유량형은 ‘구간 합계’임을 요약 문구와 근거 안내에 표시한다.
- 자금 기준일과 세금계산서 기준일이 다르면 각각의 실제 기준일을 표시한다.
- 기준일·원천 범위·결측 처리 규칙을 차트 하단에서 확인할 수 있게 한다.

## 4. 수용 기준

- `page.tsx`에 `cashTrend`, `financeChartSeries` 고정 배열이 남지 않는다.
- 모든 기간 차트가 공유 집계 함수의 결과를 사용한다.
- 월별 매출 합계가 `financeCurrentData.salesMonthly2026` 및 누적 매출과 일치한다.
- 분기 합계의 총합이 누적 매출과 일치한다.
- 주간 경계는 월요일이고, 현재 주는 실제 매출 기준일까지만 포함한다.
- 잔액 월·분기 값은 해당 구간의 마지막 관측값과 일치한다.
