# 고정자산·감가상각 통제 기획안

## 평가

- 제공된 2024·2025 합계잔액시산표에는 고정자산·감가상각 계정이 없어 과거 자산을 신뢰성 있게 복원할 수 없다.
- 현재 구매 품목은 자유입력 명칭이므로 비품·장비처럼 보인다는 이유만으로 자산으로 자동 분류하면 안 된다.
- 구매·입고·증빙·계정과목·월마감은 존재하지만 자산대장과 감가상각 전표를 잇는 원장이 없다.

## 개선된 기획 원칙

1. 승인·입고된 구매 품목은 자산 후보로만 표시하고 담당자가 명시적으로 등록한다.
2. 과거 자료와 자유입력 품목을 자동으로 자산화하지 않는다.
3. 취득원가·잔존가치·내용연수·사용개시일·자산/누계액/비용 계정을 모두 확인한다.
4. 자산 증빙을 1건 이상 첨부해야 활성화할 수 있다.
5. 기존 자산은 증빙으로 확인한 기준일·기초 누계상각을 등록하고 그 다음 월부터 연속 상각한다.
6. 초기 버전의 자동 상각방법은 정액법으로 제한하며 임의 세법 내용연수를 제안하지 않는다.
7. 월별 상각은 계획 → 전표 초안 → 승인 전기의 순서로 진행하고 잠긴 월에는 생성·전기하지 않는다.
8. 처분은 미전기 상각이 없어야 하며 외부/수동 처분전표 참조와 사유를 남긴다.

## 구축 범위

- 자산대장, 취득 원천, 위치·관리책임자, 계정 매핑, 증빙
- 구매 입고 품목의 자산 등록 후보
- 정액법 월 상각계획과 장부가액
- 감가상각 분개 초안 및 승인 전기
- 위치·책임자 이동 이력, 처분 이력
- 월마감 자동 통제와 운영 알림

## 제외 범위

- 과거 자산 자동 생성
- 정률법·생산량비례법과 세법상 자동 내용연수 추천
- 복합 처분분개 자동 작성
- 감정평가·손상차손 자동 판정
