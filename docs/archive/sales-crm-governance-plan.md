# 영업 CRM 접점·단계 통제 기획

## 현행 평가

- 거래처와 영업기회 금액은 저장되지만 실제 고객 담당자와 상담기록을 연결할 수 없다.
- 사용자가 영업 단계를 앞뒤로 자유롭게 바꿀 수 있어 단계별 근거와 실주 사유가 남지 않는다.
- 다음 행동과 기한이 비어 있거나 지나도 담당 업무가 생성되지 않는다.

## 개선된 업무 흐름

1. 거래처에 고객 담당자 이름, 직책, 이메일, 연락처를 등록한다.
2. 영업기회 상세에서 전화·이메일·회의·메모 활동을 시간순으로 기록한다.
3. 활동을 기록하면서 다음 행동과 기한을 함께 갱신할 수 있다.
4. 영업 단계는 `리드 → 요구 확인 → 제안 → 계약 협의 → 수주` 순서로만 진행한다.
5. 진행 중 어느 단계에서도 실주로 종료할 수 있지만 10자 이상의 실주 사유를 필수 기록한다.
6. 수주 전환은 승인·완료된 수주 문서가 있을 때만 허용한다.
7. 다음 행동이 없거나 기한이 지난 진행 영업기회는 통합 업무함에 표시한다.

## 원장과 통제

- 고객 담당자: 거래처 안에서 이메일·연락처·이름을 정규화한 키로 중복 차단
- 영업활동: 작성 후 수정·삭제하지 않는 접점 원장과 실제 작성자 기록
- 단계이력: 이전 단계, 이후 단계, 변경 사유, 변경자, 변경시각을 보존
- 활동의 고객 담당자는 해당 영업기회의 거래처 담당자만 선택 가능
- 단계 건너뛰기와 종결된 영업기회의 일반 변경 차단
- 영업활동과 단계변경은 감사로그에도 기록

## 평가 후 개선사항

- 단순 단계 선택 대신 다음 허용 단계만 화면에 제공한다.
- 수주 문서 없이 수주 단계로 바꾸는 기능을 차단한다.
- 실주 사유는 일반 메모가 아니라 단계이력에 고정한다.
- 활동과 다음 행동 갱신은 하나의 DB 처리 묶음으로 반영한다.
- 고객 담당자 정보는 영업 권한 사용자만 조회하며 통합 알림에는 표시하지 않는다.
