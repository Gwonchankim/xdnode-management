# 재무 데이터 어시스턴트 근거 통제 기획

## 1. 현재 평가

- 기존 답변은 정적 재무 설명문을 모델에 전달해 최신 POSTED 전표와 월마감 상태가 답변별로 증명되지 않았다.
- 답변 화면에 기준일·원천·제한이 없어 사용자가 세금계산서 공급가액, 은행 입금, 회계상 매출을 혼동할 수 있었다.
- AI 무료 한도나 연결 장애가 발생하면 승인된 ERP 근거가 있어도 답변 전체가 중단되었다.

## 2. 보완한 기획

- 숫자 계산은 서버에서만 수행한다. 2026 손익은 승인 개시잔액과 POSTED 통제 전표·지급 전표만 사용한다.
- AI는 구조화된 근거 JSON을 설명만 하며 새 숫자 계산, 원인 추정, 누락값 보완을 금지한다.
- 2024·2025 승인 결산, 2026 운영 손익, Clobe 세금계산서·자금 스냅샷을 별도 원천으로 표시한다.
- 세금계산서 공급가액과 은행의 매출성 입금은 회계상 매출과 합산하거나 동일시하지 않는다.
- 제출·마감 후 원장 해시가 달라지거나 무결성 확인이 실패하면 `검토 필요`로 낮추고 확정 표현을 금지한다.
- AI 한도·설정·연결 장애 시에도 동일한 근거 묶음으로 규칙 기반 답변을 제공하며 그 제한을 화면에 표시한다.

## 3. 구축 범위

- 답변 API: 운영 손익·원장 품질·마감 무결성·자금 현황을 동시에 계산하고 출처와 제한을 함께 반환한다.
- 기존 연말 매출 전망과 회사 정책 기반 계좌 위험 모델도 같은 근거 묶음에 포함해 설명 가능성을 유지한다.
- 화면: 답변 생성 방식, 근거 상태, 기준일, 출처별 기간·상태, 검토 제한을 답변과 함께 표시한다.
- 이동: 답변 출처를 선택하면 총계정원장, 월마감, 데이터 점검 등 해당 검증 화면으로 이동한다.

## 4. 검증 기준

- AI 프롬프트가 근거 JSON 밖의 숫자와 원인을 만들지 못하도록 명시적으로 제한한다.
- 2026 손익이 POSTED 원장 스냅샷에서 생성되는지 확인한다.
- 마감 원장 변동 시 `REVIEW_REQUIRED`가 되며 출처 상태도 검토로 표시되는지 확인한다.
- AI 장애·한도 초과 시 규칙 기반 답변에도 같은 출처와 제한이 유지되는지 확인한다.
- 정적 테스트, 순수 함수 동적 테스트, 전체 테스트와 배포 빌드를 통과해야 운영 반영한다.
