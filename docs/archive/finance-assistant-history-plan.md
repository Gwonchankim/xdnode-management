# 재무 어시스턴트 답변 감사원장 기획

## 평가

- 답변 화면은 최신 근거를 표시하지만 새로고침하면 답변과 출처가 사라져 과거 의사결정의 근거를 재현할 수 없다.
- 원장이나 회사 정책이 바뀌면 같은 질문의 결과가 달라질 수 있으므로 답변 본문만 저장하는 방식도 충분하지 않다.
- 브라우저 저장소는 사용자·기기별 임시 상태이므로 회사 감사기록의 원본으로 사용할 수 없다.

## 개선된 설계

- D1의 `finance_assistant_answers`를 추가 전용 감사원장으로 사용한다.
- 질문, 답변, 생성 방식, 근거 상태, 기준일, 전체 근거 JSON, 근거 SHA-256, 답변 SHA-256, 프롬프트 버전, 작성자를 한 행에 동결한다.
- 수정·삭제 API는 만들지 않는다. 같은 질문을 다시 실행해도 기존 행을 바꾸지 않고 새 행을 추가한다.
- AI 설정·연결·한도 문제로 규칙 기반 답변을 사용한 경우에도 동일하게 기록한다.
- 한도·연결 상태처럼 해당 응답에만 추가된 제한 문구도 실제 표시된 목록 그대로 근거 스냅샷에 합쳐 동결한다.
- 재무 읽기 권한이 있는 사용자만 최근 이력을 조회할 수 있으며, 이력 선택 시 당시 답변과 출처·제한을 그대로 복원한다.
- 감사기록 저장에 실패한 답변은 화면에 성공한 답변으로 반환하지 않는다.

## 검증 기준

- 마이그레이션과 런타임 초기화가 동일한 스키마·인덱스를 만든다.
- 답변 생성 시 한 행만 추가되고 UPDATE·DELETE 경로가 존재하지 않는다.
- 근거 JSON과 답변 해시가 결정적으로 생성되고 작성자·기준일이 보존된다.
- 최근 이력은 생성일 내림차순이며 최대 50건으로 제한된다.
- 화면에서 최근 답변을 선택하면 당시 답변, 생성 방식, 근거 상태, 출처, 제한이 복원된다.
