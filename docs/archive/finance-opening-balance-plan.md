# 2026 개시잔액 승인 통제

- 2025 결산후 합계잔액시산표에서 금액 편집 없이 2026 개시 초안을 생성한다.
- 초안 생성 시 원본 SHA-256, 계정별 원천행, 차변·대변 합계와 차이를 고정한다.
- 차대변 차이가 0원인 초안만 전자결재로 제출한다.
- 최종 승인 전 총계정원장에서는 `승인 전 참고값`으로 표시하고 공식 재무제표 기준선으로 간주하지 않는다.
- 승인 후 금액·행 수정과 삭제 API를 제공하지 않는다. 원천 정정은 새 버전·새 결재로 처리한다.
- 생성·제출·승인·반려는 이벤트 원장과 ERP 감사로그에 남긴다.
