# 법인카드·지출증빙 통제 기획안

## 현행 평가

- 지출결의 → 전자결재 → 지급원장 → 전표 → 은행 대사 흐름은 이미 존재하므로 별도 지출 시스템을 만들면 중복 비용이 발생한다.
- 현재 증빙은 파일 존재 여부만 확인하며 업무 목적, 적격증빙 여부, 세무 처리 판단과 검토자가 원장으로 남지 않는다.
- 법인카드 지급수단은 선택할 수 있지만 카드 마스터와 카드사 거래 원문이 없어 실제 사용 내역과 지출결의를 대사할 수 없다.
- 은행 대사는 지급원장과 연결되지만 지출 화면에서는 대사 잔액과 미대사 상태를 한 번에 확인하기 어렵다.
- 카드 명세서 양식이 제공되지 않았으므로 열 구조나 카드사 데이터를 추정해 자동 수입하면 안 된다.

## 개선 원칙

1. 기존 `finance_expense_requests`, 지급원장, 전표, 은행 대사를 회계 원천으로 유지한다.
2. 법인카드는 전체 번호를 저장하지 않고 카드사·별칭·끝 4자리·사용자·한도만 관리한다.
3. 카드 거래는 카드사 참조값으로 중복을 차단하고, 원화·정확한 금액의 승인된 법인카드 지출에만 수동 연결한다.
4. 증빙 검토는 업무 목적, 증빙 문서 또는 예외 사유, 세무 처리 판단, 검토자·검토시각을 남긴다.
5. 증빙 검토 전에는 증빙이 필요한 요청을 지급할 수 없고, 법인카드 거래 연결 전에는 법인카드 지급을 반영할 수 없다.
6. 지급 완료된 계좌이체·자동이체는 기존 은행 대사의 확정 금액을 그대로 사용하며 별도 대사를 만들지 않는다.
7. 동일 일자·거래처·금액의 지출은 삭제하거나 자동 병합하지 않고 중복 후보로 경고한다.
8. 잠긴 월의 카드 대사·증빙 검토는 변경할 수 없으며 검토된 증빙 삭제는 먼저 검토 재개방을 요구한다.

## 구축 범위

- 법인카드 마스터와 카드 사용 거래 원장
- 승인 지출과 카드 거래의 정확한 금액 대사
- 증빙 파일·업무 목적·세무 판단 검토 원장
- 계좌 지급의 은행 대사 상태 표시
- 중복 후보, 미증빙, 미검토, 카드·은행 미대사 알림
- 지출통제 전용 화면과 월마감 자동 통제

## 제외 범위

- 카드번호 전체값, CVC, 유효기간 저장
- 카드사 명세서 형식 추정 또는 임의 열 매핑
- OCR 결과만으로 증빙·세무 적격성을 자동 확정
- 외화 카드 거래를 환율 없이 원화 지출에 자동 연결
- 유사 거래처명·날짜만으로 카드 또는 은행 거래 자동 확정
