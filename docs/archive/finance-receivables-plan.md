# 청구서별 채권·회수 관리 기획 및 평가

## 목표

영업에서 승인된 청구서와 확정 수금을 단일 기준으로 사용하여, 재무 담당자가 미수잔액·연체·입금약속·분쟁·후속 조치를 청구서 단위로 추적한다.

## 기존 기능 평가

- 2025년 결산 거래처 잔액을 사용자가 직접 덮어쓸 수 있어 장부 원천과 관리값이 혼동될 수 있었다.
- 거래처 단위 메모만 있어 여러 청구서의 만기와 부분 수금을 구분하기 어려웠다.
- 수금 문서·배분 원장과 분리되어 회수 완료 상태를 수동으로 바꿀 수 있었다.
- 접촉 이력이 누적되지 않고 하나의 메모로 덮어써져 책임과 경과를 추적하기 어려웠다.

## 개선 원칙

1. 청구액·확정수금·미수잔액·만기일은 영업 원천에서 읽기 전용으로 제공한다.
2. 미수잔액은 승인·완료된 수금 배분만 차감하며, 작성 중 수금은 `등록 대기`로 분리한다.
3. 수금 완료는 미수잔액이 0원이 될 때 자동 종결한다. 사용자가 임의 종결하지 못한다.
4. 담당자, 입금 약속, 분쟁 사유, 다음 조치와 관리 메모만 청구서별 실행정보로 저장한다.
5. 통화·이메일·약속·분쟁 기록은 추가 전용 이력으로 보존한다.
6. 2025년 거래처 단위 기록은 참고용으로만 유지하고 2026년 청구서 합계와 섞지 않는다.

## 화면 구성

- KPI: 총 미수잔액, 연체잔액, 약속금액, 만기일·담당자 보완 건수
- 에이징: 정상, 1~30일, 31~60일, 61~90일, 90일 초과, 만기일 없음
- 회수 큐: 거래처·청구번호·만기·연체일·현재 미수·회수상태
- 상세: 원천금액 읽기 전용, 회수 실행계획, 접촉·특이사항 타임라인
- 알림: 연체, 만기일 누락, 담당자 미지정, 입금약속 경과, 다음 조치일 경과

## 검증 기준

- 부분수금은 확정 수금액만 미수잔액에서 차감한다.
- 작성·승인 대기 수금은 미수잔액을 줄이지 않고 별도 표시한다.
- 같은 청구서의 회수계획은 한 건만 유지하고 수정 시 감사로그를 남긴다.
- 접촉기록은 수정·덮어쓰기 없이 누적한다.
- 입금약속에는 날짜와 금액, 분쟁·보류에는 사유가 필수다.
- 약속금액은 현재 미수잔액을 초과할 수 없다.

## 추가 자료가 필요한 항목

공식 신용등급·신용위험 점수, 거래처 신용한도, 회수 우선순위 자동화는 회사의 신용정책과 거래처별 한도가 등록된 뒤 적용한다. 현재 위험 표시는 연체·약속·담당자·조치기한을 기반으로 한 운영 경보다.
