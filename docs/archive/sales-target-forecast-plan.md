# 영업 목표·전망 통제 기획

## 현행 평가

- 전체 파이프라인 합계만 있어 회사·조직·담당자별 목표와 비교할 수 없다.
- 예상 매출이 어떤 시점의 어떤 산식으로 계산되었는지 남지 않아 과거 전망을 재현할 수 없다.
- 수주, 청구 실적과 진행 파이프라인이 섞이면 이미 청구한 금액이 전망에 중복될 수 있다.
- 목표 수정과 승인 근거가 없어 월 중 목표를 바꿔 달성률을 왜곡할 수 있다.

## 목표 계획

1. 연도별 계획은 버전을 가지며 `작성 중 → 결재 중 → 승인`으로 진행한다.
2. 승인된 같은 연도의 이전 버전은 자동으로 대체 처리한다.
3. 목표 라인은 회사, 조직, 담당자 중 하나의 범위와 월을 기준으로 매출·매출총이익·수주 건수를 저장한다.
4. 결재 제출 후에는 목표 라인을 수정할 수 없다.
5. 승인 목표는 부분 고유 인덱스로 연도당 한 버전만 유지한다.

## 실적·전망 산식

- 확정 실적: `ACCEPTED` 또는 `COMPLETED` 청구 문서의 발행월 금액
- 확정 수주: `ACCEPTED` 또는 `COMPLETED` 수주 문서의 발행월 금액·건수
- 미청구 파이프라인: 진행 영업기회의 `max(예상매출 - 확정청구, 0) × 성공확률`
- 월 전망: 월 확정 청구 + 해당 월 마감 예정 미청구 가중 파이프라인
- 예상 매출총이익: 확정 청구는 영업기회 예상 이익률, 파이프라인은 예상매출-예상원가 비율을 적용한 참고치
- 산식 버전은 스냅샷에 고정하며 실제 회계 매출이나 원가로 오인하지 않도록 표시한다.

## 조직·담당자 귀속

- 영업기회의 `owner_employee_id`를 담당자 기준으로 사용한다.
- 조직은 인사기록의 현재 소속 조직을 조회하며, 조회 시점 조직 기준임을 표시한다.
- 회사 범위는 모든 영업기회를 합산한다.
- 목표 범위끼리는 자동 합산하지 않아 회사·조직·담당자 목표의 중복 집계를 방지한다.

## 전망 스냅샷과 알림

- 사용자가 전망을 저장하면 기준일·계획·산식 버전·월별 결과를 변경 불가능한 버전으로 보존한다.
- 승인 목표가 없거나 최신 전망이 없으면 업무 알림을 생성한다.
- 연간 전망이 목표의 90% 미만이거나 직전 스냅샷보다 10% 이상 하락하면 확인 알림을 생성한다.
- 알림에는 개인 연락처나 인사 민감정보를 포함하지 않는다.

## 평가 후 개선사항

- 실적과 전망을 한 숫자로 덮지 않고 확정 청구·확정 수주·가중 파이프라인을 나란히 제시한다.
- 조직 목표와 담당자 목표를 자동 합산하지 않고 사용자가 비교 범위를 선택하도록 한다.
- 전망 스냅샷은 현재 데이터를 복사한 근거 원장으로만 사용하고 원천 영업 문서는 변경하지 않는다.
