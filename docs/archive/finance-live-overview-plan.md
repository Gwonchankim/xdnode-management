# 재무 통합 대시보드 실시간 연결 기획

## 1. 평가

- 은행성 자산·외화예금·대출·분개장 차이는 `financeCurrentData`를 사용하지만, 최근 31일 현금흐름은 화면과 AI 프롬프트에 중복 기입되어 있었다.
- 대시보드의 재무 알림 4건은 실제 `erp_tasks` 상태와 무관해, 사용자가 업무를 완료해도 카드가 사라지지 않았다.
- ‘오늘의 자금일보’는 저장된 `finance_daily_treasury_reports`를 읽지 않는 고정 문구였다. 보고서를 작성·검토·확정해도 대시보드에 반영되지 않았다.
- 고정 문구에 ‘내부 대체거래 제외’라고 표시했지만, 현재 Clobe 집계만으로 그 제외 여부를 증명할 수 없었다.

## 2. 개선한 기획안

### 데이터 권위

| 화면 요소 | 권위 데이터 | 원칙 |
| --- | --- | --- |
| 은행성 자산·대출·환율 집중도 | `financeCurrentData` | 일일 Clobe 스냅샷과 같은 기준일 사용 |
| 최근 31일 현금흐름 | `financeCurrentInsights` | 화면과 AI가 하나의 값 사용, 계좌간 대체 포함 가능성 표시 |
| 확인할 재무 알림 | `/api/operations`의 미완료 재무 업무 | 완료 업무는 카드에서 제거, 우선순위·목적지 유지 |
| 오늘의 자금일보 | `/api/finance/daily-treasury`의 최신 버전 | 저장된 분석·상태·경고를 그대로 표시 |

### 상태 처리

- 알림·자금일보는 대시보드 진입 시 불러오고 사용자가 새로고침할 수 있다.
- 일부 API만 실패하면 성공한 데이터는 유지하고, 실패한 영역에만 ‘임의 수치 미표시’ 안내를 노출한다.
- 자금일보가 없으면 저장된 것처럼 보이지 않게 ‘작성 필요’ 상태와 원천 스냅샷 요약을 표시한다.
- 확정본은 `FINAL`, 검토본은 `REVIEWED`, 초안은 `DRAFT`로 구분한다.
- 업무 카드는 서버의 목적지(`finance:*`)로 이동한다. 목적지가 없거나 알 수 없으면 재무 운영센터로 이동한다.

## 3. 수용 기준

- 소스에 고정된 `financeAlerts`, `financeDailyBrief` 배열이 남지 않는다.
- 알림 개수는 실제 미완료 재무 업무 개수와 일치하고, 4건으로 고정되지 않는다.
- 자금일보 분석 문장은 최신 저장 버전을 표시하며 분석 출처와 보고서 상태를 함께 보여준다.
- 보고서가 없거나 API가 실패한 경우 이를 명시하고 과거 문장을 최신 분석처럼 표시하지 않는다.
- 최근 31일 현금흐름은 화면과 AI가 같은 공유 상수를 사용한다.
- 기존 권한 검사와 쓰기·확정 절차는 변경하지 않는다.
