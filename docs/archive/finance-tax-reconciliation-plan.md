# 부가세·세무 증빙 통제 기획안

## 평가

- 현재 Clobe 자료는 세금계산서의 공급가액과 문서 수만 제공하며 부가세액·과세유형·공제 여부는 제공하지 않는다.
- 세금코드 마스터는 있으나 실제 코드가 등록되지 않은 상태이므로 시스템이 일반과세 10% 등을 임의로 가정하면 안 된다.
- 월마감의 `TAX` 항목은 담당자가 완료 여부만 체크하는 수동 통제여서 신고값, 원천 대사, 증빙이 서로 연결되지 않는다.

## 기획 원칙

1. 이 화면은 공식 세무신고를 대신하지 않는 내부 검토 원장이다.
2. 공급가액 원천은 Clobe의 수정·취소 순액 스냅샷으로 고정한다.
3. 신고 공급가액·매출세액·공제/불공제 매입세액·조정세액은 홈택스 또는 이카운트에서 확인한 값만 입력한다.
4. 세율과 과세유형은 승인된 세금코드가 있을 때만 사용하며 자동 추정하지 않는다.
5. 공급가액 차이가 있으면 차이 사유를 기록하고, 증빙을 첨부해야 검토 완료할 수 있다.
6. 검토 완료는 월마감 자동 통제와 운영 알림에 연결하고, 마감 잠금 월은 수정하지 못한다.

## 구축 범위

- 월별 Clobe 매출·매입 공급가액 및 문서 수 자동 집계
- 신고값 입력, 공급가액 차이와 예상 납부/환급액 표시
- 세금코드 등록 상태, 신고값 확인, 공급가액 대사, 증빙 첨부의 4단계 검증
- 검토 완료/재개방과 감사로그
- 월마감 `TAX` 자동 통제 및 운영센터 미완료 알림

## 제외 범위

- 과세·영세·면세 자동 판정
- 법정 신고서 생성 또는 홈택스 제출
- 원천에 없는 부가세액의 10% 추정
- 세무대리인의 최종 판단 대체
