# HR 채용 보조

- HR AI의 채용·면접에서 파일 또는 붙여 넣은 이력서와 지원 포지션으로 등록안·면접 질문을 함께 생성한다.
- 추출한 이름·이메일·연락처·경력·요약과 질문지는 사용자가 수정한 뒤 저장한다. 불명확한 정보는 추정하지 않는다.
- 면접일과 시작 시간은 사용자가 입력한다. 둘 다 미정이면 서류 검토, 둘 다 있으면 직접 면접 단계로 등록한다.
- 지원자·이력서·일정·면접 질문지를 기존 hr_applicants 한 행에 함께 저장한다. 질문 목적지는 interview.questions다.
- 신규 생성은 기존 ID를 덮어쓰지 않으며 같은 이메일·연락처의 중복 등록을 서버에서 막는다. 기존 채용 권한과 감사기록을 유지한다.
- 지원자 등록은 채용 합격·오퍼·입사 전환 또는 외부 메시지 발송을 수행하지 않는다.
